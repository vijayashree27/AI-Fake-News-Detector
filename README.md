->AI Fake News & Misinformation Detection System
Overview:
This project is a lightweight prototype that detects fake, misleading, or biased news using Natural Language Processing and Amazon Bedrock. It analyzes user-provided text and returns a classification, credibility score, and brief explanation to help assess information reliability.
How It Works:
1)User enters news text or headline.
2)The system sends the input to Amazon Bedrock for analysis.
3)The model returns:
{i}Classification (Real / Fake / Biased)
{ii}Credibility Score (0–100)
{iii}Short explanation
Tech Stack:
Python • Amazon Bedrock • NLP • Boto3
Scope:
This is a proof-of-concept prototype focused on text analysis and basic credibility estimation.
